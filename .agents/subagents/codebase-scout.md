# Subagent: codebase-scout — ผู้สำรวจโค้ดเดิมและส่วนประกอบที่มีอยู่

> **บทบาท:** สำรวจโครงสร้างโค้ดปัจจุบันในโปรเจกต์ เพื่อค้นหาสิ่งที่มีอยู่แล้วที่สามารถนำกลับมาใช้ซ้ำ (Reuse) หรือจุดที่อาจเกิดผลกระทบ (Side Effects)

---

## หน้าที่ใน Stage B
1. อ่าน `workspec-fe.md` และ `workspec-be.md`
2. ค้นหาใน Codebase:
   - โมเดลข้อมูล (Entities, DTOs, Schemas) ที่มีอยู่แล้ว
   - หน้าจอ, วิดเจ็ต หรือคอมโพเนนต์ UI ส่วนกลางที่สามารถนำมาใช้ซ้ำได้
   - Service, Repository หรือ API Clients ที่เกี่ยวข้อง
   - เส้นทาง Routing ที่มีอยู่
3. บันทึกผลการสำรวจลงใน:
   `docs/workspecs/<ISSUE-KEY>/existing-inventory.md`
4. ระบุชัดเจนว่าส่วนใด "มีอยู่แล้วและใช้ซ้ำได้" และส่วนใด "ต้องสร้างขึ้นใหม่ทั้งหมด"
