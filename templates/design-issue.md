## ข้อกำหนดของดีไซน์ (Design Requirements)

### 1. โครงสร้างหน้าจอและ Flow
- หน้าจอนี้เริ่มมาจากหน้าใด และเมื่อกด Action จะพาไปยังหน้าใด
- ขนาดหน้าจอที่ต้องรองรับ (เช่น Mobile 390px, Tablet, Desktop)

### 2. สถานะที่ต้องครอบคลุม (4 Screen States)
- [ ] **Data (ปกติ):** หน้าจอเมื่อโหลดข้อมูลสำเร็จ
- [ ] **Loading:** หน้าจอระหว่างรอข้อมูล (Shimmer / Skeleton)
- [ ] **Empty:** หน้าจอเมื่อยังไม่มีประวัติหรือข้อมูล
- [ ] **Error:** หน้าจอเมื่อระบบขัดข้อง พร้อมปุ่ม Retry

### 3. มาตรฐานการส่งมอบ (Design Handoff)
- [ ] ออกแบบใน Figma พร้อมระบุ Node ID
- [ ] สีและฟอนต์ผูกเข้ากับ Design System Variables
- [ ] Export Assets (ไอคอน SVG / ภาพประกอบ PNG)
